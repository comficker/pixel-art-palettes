# ドット絵パレット — PICO-8・ゲームボーイ・CGA などのカラーコード

`pixel-art-palettes`：定番のドット絵 パレット（PICO-8、ゲームボーイ、CGA、EGA、Webセーフカラーなど）を JSON・CSV・GIMP/Aseprite 用 `.gpl`・`.hex` で収録し、最も近い色を探す小さなライブラリと CLI も付けました。

[English](README.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [한국어](README.ko.md) · **日本語**

## ファイルを使う

インストール不要です。すべてのファイルは [`data/`](data) にあり、CDN からも直接取得できます。

```
https://cdn.jsdelivr.net/npm/pixel-art-palettes/data/gpl/pico-8.gpl
https://cdn.jsdelivr.net/npm/pixel-art-palettes/data/json/pico-8.json
```

`.gpl` は Aseprite・GIMP・Krita・Inkscape に、`.hex` は Lospec 形式のエディタに読み込めます。`data/index.json` に一覧があります。

## ライブラリを使う

```bash
npm install pixel-art-palettes
```

```js
import {getPalette, nearest, remap} from 'pixel-art-palettes'

getPalette('pico-8').colors          // ['#000000', '#1D2B53', …]
nearest('#ff8800', 'game-boy-dmg')   // '#9BBC0F'  (OKLab distance)
remap(rgbaBytes, 'cga-16')           // a new RGBA array, every pixel moved to a CGA colour
```

`listPalettes(group?)`、`searchPalettes(query, {colors})`、`toGpl`、`toCsv`、`toHex` も TypeScript の型付きで使えます。

## CLI を使う

```bash
npx pixel-art-palettes list
npx pixel-art-palettes pico-8 --format gpl > pico-8.gpl
npx pixel-art-palettes nearest "#ff8800" cga-16
```

## SimplePixelArt について

[SimplePixelArt](https://simplepixelart.com) はブラウザで使える無料のドット絵エディタです。レイヤー、アニメーション、スプライトシート、Godot・Tiled 向けタイルセット、[画像をドット絵に変換するツール](https://simplepixelart.com/converter)、[パレットライブラリ](https://simplepixelart.com/palettes)があります。AI アシスタント向けには無料の MCP サーバー [simplepixelart-mcp](https://github.com/comficker/pixel-art-mcp) もあります。
