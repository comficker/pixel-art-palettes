# Sources

Every palette here comes from hardware, a published standard or a formula, so
its colour values are facts rather than anyone's creative work. The CC BY 4.0
licence (LICENSE-DATA) covers this compilation: names, notes and file formats.

| Palette | Where the values come from |
|---|---|
| PICO-8 | The 16 fixed colours of the [PICO-8](https://www.lexaloffle.com/pico-8.php) fantasy console by Lexaloffle Games. |
| Game Boy (DMG) | The four green shades of the original Game Boy screen, in the values most emulators use. |
| Game Boy Pocket | The four grey shades of the Game Boy Pocket screen. |
| CGA 16 | IBM Color Graphics Adapter RGBI palette, with the brown adjustment of colour 6 ([Wikipedia](https://en.wikipedia.org/wiki/Color_Graphics_Adapter)). |
| CGA Mode 4, palettes 0 and 1 | CGA 320×200 four-colour mode, high intensity. |
| EGA 64 | All 64 colours of the IBM Enhanced Graphics Adapter: 2 bits per channel ([Wikipedia](https://en.wikipedia.org/wiki/Enhanced_Graphics_Adapter)). |
| RGB 3-3-2 | 8-bit colour: 3 bits red, 3 green, 2 blue ([Wikipedia](https://en.wikipedia.org/wiki/8-bit_color)). |
| Web-safe 216 | Six levels per channel ([Wikipedia](https://en.wikipedia.org/wiki/Web_colors#Web-safe_colors)). |
| 1-bit, Grayscale 4/8/16, Primary 8 | Black and white, evenly spaced greys, RGB primaries and secondaries. |

## Not included (yet)

Artist-made palettes — Sweetie 16 (GrafxKid), ENDESGA 32/64 (ENDESGA),
AAP-64 (Adigun A. Polack), Resurrect 64 (Kerrie Lake) and others — are left out
until their authors agree to them being redistributed under CC BY 4.0. If you
made a palette and would like it here, open an issue.
