# Paletas de pixel art — códigos hex de PICO-8, Game Boy, CGA y más

`pixel-art-palettes`: paletas de colores de pixel art clásicas —PICO-8, Game Boy, CGA, EGA, colores web seguros y más— en archivos JSON, CSV, `.gpl` de GIMP/Aseprite y `.hex`, con una pequeña librería para buscar el color más cercano y una CLI.

[English](README.md) · [简体中文](README.zh.md) · **Español** · [Português](README.pt.md) · [Русский](README.ru.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

## Paletas

## Usar los archivos

Sin instalar nada: todos los archivos están en [`data/`](data), o directamente desde un CDN:

```
https://cdn.jsdelivr.net/npm/pixel-art-palettes/data/gpl/pico-8.gpl
https://cdn.jsdelivr.net/npm/pixel-art-palettes/data/json/pico-8.json
```

`.gpl` se importa en Aseprite, GIMP, Krita e Inkscape; `.hex` en editores tipo Lospec; `data/index.json` los lista todos.

## Usar la librería

```bash
npm install pixel-art-palettes
```

```js
import {getPalette, nearest, remap} from 'pixel-art-palettes'

getPalette('pico-8').colors          // ['#000000', '#1D2B53', …]
nearest('#ff8800', 'game-boy-dmg')   // '#9BBC0F'  (OKLab distance)
remap(rgbaBytes, 'cga-16')           // a new RGBA array, every pixel moved to a CGA colour
```

También exporta `listPalettes(group?)`, `searchPalettes(query, {colors})`, `toGpl`, `toCsv` y `toHex`, con tipos de TypeScript.

## Usar la CLI

```bash
npx pixel-art-palettes list
npx pixel-art-palettes pico-8 --format gpl > pico-8.gpl
npx pixel-art-palettes nearest "#ff8800" cga-16
```

## Sobre SimplePixelArt

[SimplePixelArt](https://simplepixelart.com) es un editor de pixel art gratuito en el navegador: capas, animación, sprite sheets, tilesets para Godot y Tiled, un [convertidor de imagen a pixel art](https://simplepixelart.com/converter) y una [biblioteca de paletas](https://simplepixelart.com/palettes). Para asistentes de IA hay un servidor MCP gratuito, [simplepixelart-mcp](https://github.com/comficker/pixel-art-mcp).
